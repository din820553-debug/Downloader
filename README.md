# Downloader 2.0 — Android

Нативный загрузчик на Kotlin для Android 10+, без `yt-dlp` и FFmpeg. Исходники открыты.

## Поддерживается в 2.0
- Прямые HTTP(S)-ссылки на MP4, WebM, MOV, MKV, MP3, M4A, AAC.
- HLS VOD (.m3u8) **без шифрования**, сегменты TS или fMP4; выбор качества из master-плейлиста.
- Извлечение прямых медиаадресов из HTML/метатегов и некоторых встроенных JavaScript-конфигураций.
- **Встроенный браузер:** если плеер загружается через JavaScript, откройте страницу, запустите видео и выберите обнаруженный прямой медиапоток.
- Докачка обычных файлов с HTTP Range, сохранение частичных HLS-сегментов, пауза/продолжение, очередь и история.
- Превью, скачанные МБ/ГБ и общий размер (если его сообщает сервер).
- **Папки по исходному сайту:** `Загрузки/Downloader/youtube.com/`, `Загрузки/Downloader/twitch.tv/`, `Загрузки/Downloader/example.com/` и т. д.
- Удаление записей истории, сохранённых файлов и недокачанных данных.

## Важные ограничения
- Это **первый нативный движок**, а не универсальный аналог yt-dlp. Нельзя гарантировать поддержку любой страницы на YouTube, Twitch и других крупных площадках: поток может быть доступен только через JavaScript, авторизацию или нестандартный API.
- Нативный анализатор не расшифровывает DRM и не обходит ограничения доступа.
- HLS в формате MPEG-TS сохраняется как `.ts` без перекодирования. Некоторые медиаплееры Android могут требовать сторонний проигрыватель. HLS с отдельной аудиодорожкой и зашифрованные плейлисты пока не поддерживаются полноценно.
- Нельзя обещать MP3-конвертацию без FFmpeg: аудио сохраняется в исходном формате, если доступен самостоятельный аудиофайл.
- Пауза HTTP зависит от поддержки сервером Range; при отсутствии Range докачивание возобновится с начала. Для HLS сохраняются уже загруженные сегменты, если плейлист остаётся неизменным.
- Папка рассчитывается по исходной ссылке, включая случаи, когда браузер обнаруживает CDN-адрес.
- Скачивайте только файлы, на сохранение которых у вас есть право.

## Получение APK
[Android APK Actions](../../actions/workflows/android.yml) — тестовая APK сборка доступна в Artifacts (ZIP). Для прямой установки без ZIP и будущих обновлений поверх старой версии используйте подписанную сборку через [Releases](../../releases).

Чтобы GitHub публиковал подписанный релиз, владелец репозитория должен один раз настроить **приватные** Actions Secrets `DOWNLOADER_KEYSTORE_B64` и `DOWNLOADER_KEYSTORE_PASSWORD`. Alias ключа — `downloader`. **Не загружайте JKS или пароль в репозиторий.** После правильной настройки 2.0 и следующие версии смогут использовать одну подпись. Старые debug APK могут потребовать однократную переустановку.

## Разработка
Android Studio, Kotlin, AndroidX, Material Components, Coil и Android MediaStore.
- `NativeEngine.kt` — поиск доступных медиа, HLS-манифесты, заголовки HTTP.
- `NativeTransfer.kt` — загрузка байтов, частичные файлы, HLS-сегменты.
- `BrowserActivity.kt` — ручной захват сетевых запросов WebView на видеостранице.
- `SiteFolders.kt` — организация файлов по домену исходной страницы.
- `DownloadService.kt` — фоновая очередь, отмена, пауза и публикация MediaStore.

Сборка: Gradle 8.11.1, JDK 17. Отладочный вариант: `gradle :app:assembleDebug`. Прогресс и работа конкретных сайтов требуют проверки на реальном устройстве.
