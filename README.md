# Downloader 2.0 — Android

Нативный загрузчик на Kotlin для Android 10+, без `yt-dlp` и FFmpeg. Исходники открыты.

## Поддерживается в 2.0
- Прямые HTTP(S)-ссылки на MP4, WebM, MOV, MKV, MP3, M4A, AAC.
- HLS VOD (.m3u8) **без шифрования**, сегменты TS или fMP4; выбор качества из master-плейлиста. Счётчик байтов обновляется во время загрузки каждого фрагмента.
- Извлечение прямых медиаадресов из HTML/метатегов и некоторых встроенных JavaScript-конфигураций.
- Twitch: отдельная попытка получения доступных ссылок для клипов и VOD через веб-интерфейс воспроизведения (неофициальный, может меняться). Прямые эфиры не поддерживаются.
- YouTube: нативный анализ открытых совмещённых видео+аудиопотоков. Не поддерживаются отдельные аудио/видео дорожки без объединения, DRM, динамические подписи и требующие дополнительных токенов потоки.
- **Встроенный браузер:** если плеер загружается через JavaScript, откройте страницу, запустите видео и выберите обнаруженный прямой медиапоток.
- Докачка обычных файлов с HTTP Range, сохранение частичных HLS-сегментов, пауза/продолжение, очередь и история.
- Превью, скачанные МБ/ГБ и общий размер (если его сообщает сервер).
- **Папки по исходному сайту:** `Загрузки/Downloader/youtube.com/`, `Загрузки/Downloader/twitch.tv/`, `Загрузки/Downloader/example.com/` и т. д.
- Удаление записей истории, сохранённых файлов и недокачанных данных.

## Поиск видео на разных сайтах (2.0.5)

- Распознаются старые Twitch-ссылки вида `https://www.twitch.tv/channel/v/12345678`, современные `/videos/12345678` и встроенные ссылки Twitch Player. Это не восстанавливает удалённые записи.
- Для сайтов с JavaScript нажми «Открыть страницу и найти поток», дождись загрузки, запусти видео кнопкой Play, нажми «Найти» и выбери обнаруженный открытый MP4/HLS.
- Встроенный браузер ищет видео в элементах `video`/`source`, загруженных ресурсах и доступных iframe; учитывает ссылки на медиапотоки без расширения.
- HTML с экранированными `\\/` и `\\u002F` обрабатывается лучше.
- Если сервер не выдаёт прямой поток, контент защищён DRM или запись удалена, загрузка может оставаться недоступной.
- Тестовые APK из GitHub Actions имеют временный сертификат. При конфликте подписи обновление поверх старой тестовой сборки может не установиться; не отключай защиту банка или телефона ради установки.

## Исправление проверки ссылок (2.0.4)

- Предпросмотр и кнопка «Проверить» ограничены 12 секундами сетевой проверки; интерфейс автоматически выходит из ожидания через 14 секунд.
- Если поток не удалось определить, можно попробовать встроенный браузер. Загрузка не выдаётся за успешную без получения и проверки самого файла.
- Перед скачиванием поиск медиапотока ограничен 25 секундами. Это не лимит длительности скачивания: передача большого файла по-прежнему может занимать сколько потребуется.
- Сборка PREVIEW имеет отдельное имя и пакет `com.dindownloader.app.preview`, чтобы не конфликтовать с предыдущими временно подписанными APK.
- Автоматический тест проверяет зависший HTTP-сервер и завершение попытки после таймаута.

## Важные ограничения
- Это **первый нативный движок**, а не универсальный аналог yt-dlp. Нельзя гарантировать поддержку любой страницы на YouTube, Twitch и других крупных площадках: поток может быть доступен только через JavaScript, авторизацию или нестандартный API.
- При завершении проверяется контейнер видео, а при известной длительности — длительность файла или HLS-плейлиста. Короткие предпросмотры больше не должны считаться готовым полным роликом, когда обнаружено несоответствие.
- Нативный анализатор не расшифровывает DRM и не обходит ограничения доступа.
- Если сервер отдаёт HTML вместо файла, приложение покажет ошибку и предложит открыть видео во встроенном браузере. Если сайт блокирует загрузку, универсального обхода нет.
- HLS в формате MPEG-TS сохраняется как `.ts` без перекодирования. Некоторые медиаплееры Android могут требовать сторонний проигрыватель. HLS с отдельной аудиодорожкой и зашифрованные плейлисты пока не поддерживаются полноценно.
- Нельзя обещать MP3-конвертацию без FFmpeg: аудио сохраняется в исходном формате, если доступен самостоятельный аудиофайл.
- Пауза HTTP зависит от поддержки сервером Range; при отсутствии Range докачивание возобновится с начала. Для HLS сохраняются уже загруженные сегменты, если плейлист остаётся неизменным.
- Папка рассчитывается по исходной ссылке, включая случаи, когда браузер обнаруживает CDN-адрес.
- Скачивайте только файлы, на сохранение которых у вас есть право.

## Проблемы с установкой

Сборки из GitHub Actions, подписанные временным Android debug-ключом,
**нельзя установить поверх предыдущего APK с другой подписью**.
В версии 2.0.2 тестовая сборка получила собственный идентификатор
`com.dindownloader.app.test` и отображается как **Downloader TEST**. Версия 2.0.3 BETA
использует `com.dindownloader.app.beta` и устанавливается рядом с ней.
Она устанавливается **рядом** с ранее установленным `com.dindownloader.app`,
не стирая его историю или медиафайлы. У тестовой версии отдельные данные.

Для будущих обновлений того же приложения без удаления требуется постоянная
приватная подпись (секреты GitHub Actions ниже). Тестовая APK всегда сохраняется в **Actions → Artifacts**, а публикация в
Releases зависит от разрешений GitHub для репозитория.
Если установка долго висит даже как нового приложения, проверьте свободное
место, разрешение «Установка неизвестных приложений» для файлового менеджера
и попробуйте открыть APK из папки «Загрузки», а не из предпросмотра браузера.

## Получение APK
[Android APK Actions](../../actions/workflows/android.yml) — тестовая APK сборка доступна в Artifacts (ZIP). Для прямой установки без ZIP и будущих обновлений поверх старой версии используйте подписанную сборку через [Releases](../../releases).

Чтобы GitHub публиковал подписанный релиз, владелец репозитория должен один раз настроить **приватные** Actions Secrets `DOWNLOADER_KEYSTORE_B64` и `DOWNLOADER_KEYSTORE_PASSWORD`. Alias ключа — `downloader`. **Не загружайте JKS или пароль в репозиторий.** После правильной настройки 2.0 и следующие версии смогут использовать одну подпись. Старые debug APK могут потребовать однократную переустановку.

## Разработка
Android Studio, Kotlin, AndroidX, Material Components, Coil и Android MediaStore.
- `NativeEngine.kt` — поиск доступных медиа, HLS-манифесты, заголовки HTTP.
- `NativeTransfer.kt` — загрузка байтов, частичные файлы, HLS-сегменты.
- `BrowserActivity.kt` — ручной захват сетевых запросов WebView на видеостранице.
- `SiteFolders.kt` — организация файлов по домену исходной страницы.
- `DownloadService.kt` — фоновая очередь, отмена, пауза и публикация MediaStore.

Сборка: Gradle 8.11.1, JDK 17. В версии 2.0.1 исправлены обновление HLS-прогресса во время скачивания, проверка URL при HTTP 403/405 и обработка Twitch клипов/VOD. Отладочный вариант: `gradle :app:assembleDebug`. Прогресс и работа конкретных сайтов требуют проверки на реальном устройстве.
