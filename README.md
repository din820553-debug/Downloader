# Downloader — Android

Нативное Android-приложение для загрузки разрешённого к сохранению видео и аудио с сайтов, поддерживаемых **yt-dlp** (YouTube, Twitch VOD/Clips, Vimeo и другие).

## Возможности
- Вставка ссылки и получение ссылки через «Поделиться».
- Название, обложка и отдельная строка «Общий размер файла» перед загрузкой (если известен).
- Превью в истории, «Скачано / Общий размер» в МБ/ГБ; при неизвестной длине потока честно показываем «пока неизвестен».
- Удаление записей из истории или сохранённых файлов (с подтверждением).
- MP4 (максимум, 1080p, 720p, 480p, 360p), MP3 и M4A.
- Очередь задач, пауза/продолжение с сохранением частичных файлов, отмена, история загрузок.
- Резервный способ загрузки: альтернативный выбор потока и транспорт HLS через FFmpeg, если обычная загрузка не удалась.
- Фоновая загрузка через foreground service с уведомлением.
- Файлы в **Загрузки/Downloader** через MediaStore без полного доступа к памяти.
- Переключатель загрузки плейлиста.
- Русскоязычный тёмный интерфейс.

## Установка APK и обновления

**Важно:** старые версии v1.0–v1.1 собирались с временной отладочной подписью GitHub Actions. Поэтому обновить их поверх себя невозможно — подпись отличается. После однократной установки **стабильно подписанной версии** последующие релизы можно устанавливать поверх приложения без удаления.

Для публикации подписанной версии владелец репозитория должен один раз добавить в [Settings → Secrets and variables → Actions](../../settings/secrets/actions) два секрета:

- `DOWNLOADER_KEYSTORE_B64` — содержимое приватного JKS в Base64 (без переносов строк).
- `DOWNLOADER_KEYSTORE_PASSWORD` — пароль от этого JKS; внутри используется alias `downloader`.

**Приватный JKS, пароль и Base64 нельзя коммитить в публичный репозиторий!** Сохраните резервную копию приватного ключа: при его потере обновления под прежней подписью станут невозможны.

После добавления обоих секретов запустите [Actions → Android APK → Run workflow](../../actions/workflows/android.yml). Успешная сборка автоматически опубликует прямой APK в [Releases](../../releases). До настройки секретов Actions сохраняет только **TEST** APK в ZIP для диагностики; его подпись непостоянна и его нельзя использовать для штатных обновлений.

Пауза сохраняет недокачанные файлы в частном хранилище приложения. Продолжение зависит от поддержки докачки сайтом: для некоторых потоков потребуется повторная загрузка частей. Не очищайте данные приложения между паузой и продолжением.

Приложение поддерживает Android 10+ (arm64). Сборка: Gradle 8.11.1, JDK 17.

## Ограничения
- Сайты поддерживаются только в пределах возможностей актуального движка yt-dlp; не каждый сайт или отдельный ролик доступен. DRM, закрытые видео и вход в аккаунт не обходятся.
- Для некоторых источников могут требоваться cookies, авторизация или дополнительная конфигурация (не реализованы в этой версии).
- Фоновые загрузки могут ограничиваться энергосбережением устройства.
- При первом использовании приложение пытается обновить yt-dlp через GitHub; если сеть недоступна, остаётся встроенная версия. Проверка выполняется не чаще раза в сутки.
- Используйте только с файлами, на загрузку которых у вас есть право. Соблюдайте правила сервисов и законодательство.
