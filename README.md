# Downloader — Android

Нативное Android-приложение для загрузки разрешённого к сохранению видео и аудио с сайтов, поддерживаемых **yt-dlp** (YouTube, Twitch VOD/Clips, Vimeo и многие другие).

## Возможности
- Вставка ссылки и получение ссылки через «Поделиться».
- Информация о ролике перед загрузкой.
- MP4 (максимум, 1080p, 720p, 480p, 360p), MP3 и M4A.
- Очередь задач, прогресс, отмена, история загрузок.
- Фоновая загрузка через foreground service с уведомлением.
- Файлы в **Загрузки/Downloader** через MediaStore без полного доступа к памяти.
- Переключатель загрузки плейлиста.
- Русскоязычный тёмный интерфейс.

## Сборка APK
1. Откройте вкладку [Actions](../../actions).
2. Запустите **Android APK** → **Run workflow** либо сделайте push.
3. Откройте завершённый запуск → **Artifacts** → **Downloader-debug-APK**.
4. Распакуйте ZIP и установите `app-debug.apk` на телефон (Android 10 или новее).

В Android Studio: откройте проект и выполните `assembleDebug` (Gradle 8.11.1, JDK 17). GitHub Actions устанавливает Gradle автоматически.

## Ограничения
- Сайты поддерживаются только в пределах возможностей актуального движка yt-dlp; не каждый сайт или отдельный ролик доступен. DRM, закрытые видео и вход в аккаунт не обходятся.
- Для некоторых источников могут требоваться cookies, авторизация или дополнительная конфигурация (не реализованы в этой версии).
- Фоновые загрузки могут ограничиваться энергосбережением устройства.
- Для обновления yt-dlp требуется обновить версию библиотеки или использовать поддерживаемый ею механизм обновления.
- Используйте только с файлами, на загрузку которых у вас есть право. Соблюдайте правила сервисов и законодательство.

## Технологии
Kotlin, AndroidX, Material Components, MediaStore, [youtubedl-android](https://github.com/yausername/youtubedl-android) и FFmpeg.
