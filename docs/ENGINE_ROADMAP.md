# План расширения движков и возможностей Downloader

Версия 2.1.0 HYBRID уже позволяет выбрать **Kotlin Native** или **yt-dlp + FFmpeg** в одном приложении. Сторонние модули следует добавлять только при реальной пользе: лишние бинарные зависимости утяжеляют APK, влияют на время установки и могут вызывать защитные предупреждения.

## Приоритет движков

| Порядок | Модуль | Польза | Ограничения |
| --- | --- | --- | --- |
| 1 | **Kotlin Native** (реализован) | Прямые HTTP-файлы, HLS VOD, минимальная нагрузка | Не объединяет отдельные AV-потоки |
| 2 | **yt-dlp + FFmpeg** (восстановлен) | Много экстракторов, объединение видео и аудио, MP3 | Тяжёлые нативные зависимости; возможна устаревшая версия сайта |
| 3 | **Media3 Offline** | Официальный Android API для скачивания HLS/DASH в фон и офлайн-кеш | Это НЕ движок поиска ссылок. Нужна отдельная экспортная обработка сохранённых сегментов |
| 4 | **NewPipe Extractor** | Независимые извлекатели для YouTube, PeerTube, SoundCloud, Bandcamp | Не поддерживает все сайты; API и правила площадок меняются |
| 5 | **aria2** | Многопоточная HTTP(S)-загрузка уже известного URL | Не ищет ссылки на страницы видео; отдельный исполняемый модуль |

Справочные источники:
- Media3: https://developer.android.com/media/media3/exoplayer/downloading-media
- NewPipe Extractor: https://github.com/TeamNewPipe/NewPipeExtractor
- aria2: https://github.com/aria2/aria2

## Улучшения приложения

**Сначала реализовать:** выбор движка для каждой задачи, ручной повтор через запасной движок и копирование ошибки (в 2.1 уже есть); диагностика ссылок с указанием HTTP-кода, источника ошибки и доступных потоков; режим только Wi-Fi и пауза при мобильной сети; стабильная приватная подпись Android release APK.

**Затем:** отдельный экран доступных разрешений, кодеков и аудиодорожек; выбор субтитров; уведомления с действиями пауза/продолжить; планировщик загрузки; проверка целостности и обнаружение короткого предпросмотра; экспорт/импорт истории без секретных cookies.

**На будущее:** ручное «Авто: выбрать движок» с явным отчётом о том, какой выбран; скачивание большого количества медиа по ссылкам только с согласия пользователя; расширение браузера для открытых плееров, но без сбора паролей или логинов.

## Безопасность и совместимость

- Нельзя обходить антифрод и защиту банков. Если APK вызывает предупреждение, нужно проверять происхождение, хэши, зависимости и AndroidManifest.
- Выпускать постоянные обновления лучше **одним стабильным ключом подписи**, в отличие от случайных debug-подписей GitHub Actions.
- Для малых устройств полезно предоставлять *два APK*: Lite (только Kotlin) и Hybrid (Kotlin + yt-dlp + FFmpeg). В 2.1 поставляется Hybrid, а последняя Lite-сборка осталась в истории проекта.
- Не скачивать и не устанавливать дополнительные бинарники скрытно; любые обновления движков требуют явного согласия и проверки подлинности.
- DRM и запрещённые/недоступные медиа не поддерживать обходными методами.
