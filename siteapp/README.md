# VideoSpace — отдельное Android-приложение для одного сайта

Это **самостоятельный APK**, устанавливается рядом с Downloader, со своим значком, интерфейсом и отдельной историей загрузок.

## Как пользоваться

1. При первом запуске вставьте ссылку **HTTPS** на видеостраницу нужного сайта и нажмите «Открыть». Первый домен сохраняется локально как выбранный сайт. Приложение не упоминает его название в названии APK или исходниках.
2. Если ролик требует аккаунта, нажмите **«Войти на сайте»** и авторизуйтесь через оригинальную страницу. Приложение не просит и не перехватывает пароль.
3. Перейдите на страницу ролика и нажмите **«Скачать видео»**. Основной движок — yt-dlp + FFmpeg (собственные библиотеки Android).
4. Если источник открытый, можно запустить ролик в WebView, нажать **«Найти поток»** и выбрать MP4/HLS как запасной вариант.
5. Готовый файл появится в `Загрузки / Downloader / <домен>/`.

## Авторизация и приватность

- Android WebView сам хранит сессионные cookies для вошедшего пользователя. Приложение не получает и не сохраняет пароль.
- Перед запросом yt-dlp cookies выбранного сайта могут передаваться во **временный приватный Netscape cookie-файл**. Файл удаляется сразу после запроса, даже при ошибке. Cookies других доменов не экспортируются.
- Основной экран загрузок не содержит рекламного SDK, аналитики, выдачи cookie наружу или формы логина.
- Приложение не расшифровывает DRM и не гарантирует работу сайтов с ограничениями, изменяющимся API или удалёнными видео.
- Если банковское приложение предупреждает о риске, не выключайте защиту ради установки. Сборки GitHub Actions временно подписаны debug-ключами, пока не настроена постоянная подпись.

## Сборка

`gradle :siteapp:assembleDebug`

Результат: `siteapp/build/outputs/apk/debug/siteapp-debug.apk`.

В GitHub Actions готовый файл называется `VideoSpace-Standalone-v1.0.0.apk`.

Этот модуль переиспользует проверенные функции сохранения файлов, разрешения URL и очередь из Downloader, но имеет **другой applicationId** `com.dindownloader.sitevideo`, запуск и пользовательскую сессию.
